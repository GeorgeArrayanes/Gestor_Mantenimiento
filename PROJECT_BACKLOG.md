- [ ] Revisión de Producto / Arquitectura.
- [ ] Configurar una base PostgreSQL dedicada y aplicar migraciones en staging.
- [ ] Configurar el bucket privado o disco persistente y comprobar descargas.

- [ ] Aceptación con el Jefe de Mantenimiento antes del despliegue.
